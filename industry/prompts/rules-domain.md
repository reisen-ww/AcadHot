
【学术领域翻译规则 — 本平台 100% 是前沿科技与生命科学内容，严格遵守】

1. 歧义默认值：以下词在中文有非学术歧义，**一律按学术含义翻译**：
   - Cell = 细胞（生物学语境；指期刊时保留 Cell，不译“牢房”）
   - Culture = 培养（细胞/微生物语境，不译“文化”）
   - Expression = 表达（基因/蛋白语境，不译“表情”“表达方式”）
   - Translation = 翻译（蛋白合成语境，不译“译文”）
   - Transcription = 转录（不译“听写”“抄录”）
   - Target = 靶点 / 靶标（药物与基因语境，不译“目标”作泛义）
   - Model = 模型（统计、机器学习与动物模型语境）；动物语境可写“模型小鼠”“动物模型”
   - Phase = 期（临床试验语境，如 Phase III = III 期）
   - Control = 对照（试验语境，如 control group = 对照组，不译“控制”）
   - Enrollment = 入组（不译“注册”“招生”）
   - Endpoint = 终点（临床试验语境，如 primary endpoint = 主要终点）
   - Arm = 组 / 试验组（如 treatment arm = 治疗组，不译“手臂”）
   - Dosing = 给药（不译“剂量计算”）
   - Resolution / Resolve = 解析（结构生物学语境，如 high-resolution structure = 高分辨率结构）
   - Submission = 投稿（论文语境），Preprint = 预印本，Peer review = 同行评议
   - Retraction = 撤稿，Correction / Erratum = 更正 / 勘误
   - Cohort = 队列（流行病学与临床语境，不译“同伙”）
   - Incidence / Prevalence = 发病率 / 患病率（两者不可混用）
   - Bank = 库（如 biobank = 生物样本库），Chip = 芯片（不译“薯条”）

2. 以下专有名词**一律保留英文原文**，不翻译不加中文括注：
   - 基因、蛋白、分子与工具：CRISPR / Cas9 / dCas9 / TALEN / ZFN / CAR-T / TCR-T / iPSC / mRNA / tRNA / siRNA / ASO / AAV / LNP / PD-1 / PD-L1 / CTLA-4 / HER2 / EGFR / BRCA1 / APOE4 / TP53 / p53 / tau / amyloid-beta / alpha-synuclein
     **规则**：基因与蛋白名（含全大写、希腊字母与数字编号）一律保留原文写法，不改大小写、不加斜体以外的修饰
   - 期刊与平台（举例 + 通用规则）：Nature / Science / Cell / NEJM / The Lancet / JAMA / BMJ / PNAS / arXiv / bioRxiv / medRxiv / The New England Journal of Medicine
     **规则**：期刊名保留原文，子刊写全名（Nature Medicine 不写成“自然·医学”）
   - 机构与公司：NIH / FDA / NMPA / EMA / WHO / CDC / NSFC / CAS / CERN / ITER / HHMI / MIT / Caltech / DeepMind / OpenAI / NVIDIA / Moderna / BioNTech / Pfizer
     **规则**：任何 2-5 字母的全大写机构缩写，默认保留英文
   - 监管与临床缩写：IND / NDA / BLA / ANDA / PMA / IDE / RCT / IRB / GMP / GLP / GCP / OS / PFS / ORR / AE / SAE / ITT / ADR / IIT
     **规则**：任何 2-5 字母的全大写医学与监管缩写，默认保留英文
   - 物理与材料术语：qubit / spin / phonon / exciton / perovskite / graphene / MXene / MOF / LLZO / SQUID / tokamak / stellarator / LHC / JWST / eV / TeV / meV
   - 技术与计算：AI / LLM / GPU / TPU / transformer / diffusion / AlphaFold / Cryo-EM / NMR / XRD / XPS / SEM / TEM / PCR / qPCR / scRNA-seq / ATAC-seq / flow cytometry / Western blot
   - 通用技术：API / SDK / CLI / DOI / ORCID / PMID / HPC / FAIR / preprint server

3. 中国机构**优先用官方中文名**（首次出现可双标“国家药品监督管理局（NMPA）”，后续选一种保持一致）：
   - 中国科学院（CAS）/ 中国医学科学院 / 国家自然科学基金委员会（NSFC）/ 国家药品监督管理局（NMPA）/ 中国疾病预防控制中心（中国 CDC）/ 科技部 / 国家卫健委 / 中国科学技术大学 / 清华大学 / 北京大学 / 复旦大学 / 上海交通大学 / 浙江大学

4. 代码 / 命令 / URL / 数字单位 **一字不改**保留：
   - 反引号代码 `code` 不翻译
   - 基因序列、蛋白登录号（P12345）、临床试验登记号（NCT01234567 / ChiCTR…）、DOI、PMID 不译不改写
   - URL 原样
   - 数字+单位：42 名受试者 / 12.5% / 3.2 倍 / 10 mg/kg / 240 周 / 1.5 T / 300 K / 5 nm / p = 0.003 / 95% CI 0.42–0.88 / 21 万例
   - 样本量、终点值、置信区间、剂量、浓度、温度、尺度和统计量必须保留原文的阿拉伯数字与单位；不要把 “n = 42” 改写成“四十余名受试者”，也不要把 “p < 0.001” 改写成“差异显著”
